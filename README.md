# בית אור – שיבוץ שיעורים למרחב הלמידה

אתר קטן לבית הספר **בנות מנחם**, שבו המורות משתבצות לשיעורים במרחב הלמידה "בית אור".

- הלוח מחולק לשבועות לפי **פרשת השבוע**, עם תאריך עברי ולועזי, ראשי חודשים וחגים.
- ימים ראשון–שישי, **5 שיעורים** בכל יום.
- ההרשמה פתוחה **שבוע וחצי קדימה** (10 ימים). בכל יום נפתח יום נוסף.
- מורה שמשתבצת תופסת את השעה. מורה אחרת תראה שהשעה תפוסה ומי השתבצה. אם שתיים לוחצות בדיוק באותו רגע, רק הראשונה נקלטת.
- "השיבוצים שלי": כל מורה רואה את השיבוצים הקרובים שלה ויכולה לבטל אותם.
- **צד ניהול** (בכפתור "ניהול" + קוד):
  - רשימת המורות: הוספה, עריכה, מחיקה, סימון כ"לא פעילה", הדבקת רשימה שלמה בבת אחת.
  - קוד אישי (לא חובה) לכל מורה. אם הוגדר, המורה מקלידה אותו בהשתבצות ויכולה לבטל מכל מכשיר.
  - כל השיבוצים, עם סינון לפי מורה ואפשרות לבטל כל שיבוץ.
  - מספר השיבוצים של כל מורה.

הנתונים נשמרים בגיליון Google Sheets (לשוניות "שיבוצים" ו"מורות"), כך שאפשר גם לצפות בהם ישירות בגיליון.

## פריסה ב־Railway (האתר החי)

האתר רץ ב־Railway כשרת Node קטן (`server.js`, ללא תלויות). הנתונים נשמרים בקובץ על volume קבוע.

| משתנה | מה זה |
|---|---|
| `ADMIN_CODE` | קוד הכניסה לצד הניהול |
| `DATA_DIR` | תיקיית הנתונים (`/data`, שם מחובר ה־volume) |

כל דחיפה לענף שמחובר ל־Railway מעדכנת את האתר אוטומטית. הגדרות כמו שעות השיעורים נמצאות ב־`CONFIG` בראש `server.js`.

הרצה מקומית: `ADMIN_CODE=1234 npm start` ואז http://localhost:3000

## חלופה: התקנה ב־Google Apps Script (כ־10 דקות)

1. ב־Google Drive יוצרים **גיליון חדש** ונותנים לו שם, למשל "בית אור – שיבוצים".
2. בגיליון: **תוספים (Extensions) ← Apps Script**.
3. בעורך שנפתח:
   - מוחקים את מה שכתוב בקובץ `Code.gs` ומדביקים את התוכן של [`src/Code.gs`](src/Code.gs).
   - לוחצים **+ ← HTML**, קוראים לקובץ `Index` (בדיוק כך) ומדביקים את התוכן של [`src/Index.html`](src/Index.html).
   - שומרים (Ctrl+S).
4. בוחרים בפונקציה **`setup`** בתפריט העליון ולוחצים **הפעלה (Run)**. מאשרים את ההרשאות שגוגל מבקשת.
   ב"יומן הביצוע" יופיע **קוד הניהול**. כדאי לשמור אותו.
5. **פריסה (Deploy) ← פריסה חדשה (New deployment)** ← סוג: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - לוחצים Deploy ומעתיקים את הקישור (מסתיים ב־`/exec`).
6. שולחים את הקישור למורות. נכנסים עם קוד הניהול ומוסיפים את רשימת המורות (אפשר להדביק את כל השמות בבת אחת).

> אם לבית הספר יש Google Workspace, אפשר לבחור בשלב 5 "Anyone within <הדומיין>" כדי שרק חשבונות בית הספר ייכנסו.

## התאמות

בראש הקובץ `Code.gs` יש אובייקט `CONFIG`:

| הגדרה | מה זה |
|---|---|
| `LESSONS` | שמות השיעורים ושעותיהם, למשל `{ id: 1, name: 'שיעור 1', time: '08:00–08:45' }` |
| `DAYS_AHEAD` | כמה ימים קדימה פתוח לשיבוץ (ברירת מחדל 10) |
| `SCHOOL_DAYS` | ימי הלימודים (0=ראשון … 5=שישי) |
| `CLOSED_DATES` | ימים שבהם המרחב סגור, למשל `{ '2026-12-10': 'טיול שנתי' }` |

**החלפת קוד הניהול:** ב־Apps Script ← ⚙️ הגדרות הפרויקט ← Script properties ← `ADMIN_CODE`.

**אחרי שינוי בקוד** צריך לעדכן את הפריסה: Deploy ← Manage deployments ← ✏️ ← Version: **New version** ← Deploy. הקישור נשאר אותו קישור.

## תצוגה מקדימה

פתיחה של `src/Index.html` ישירות בדפדפן מציגה את האתר במצב הדגמה. הנתונים נשמרים רק בדפדפן, וקוד הניהול לדוגמה הוא `1234`.

## איך זה עובד

- `src/Code.gs`: צד השרת (Google Apps Script). קורא וכותב לגיליון, נועל את הגיליון בזמן שיבוץ כדי שלא ייווצרו שיבוצים כפולים, ומושך את פרשות השבוע והחגים מ־[Hebcal](https://www.hebcal.com) (לוח ארץ ישראל, נשמר במטמון ל־6 שעות).
- `src/Index.html`: האתר עצמו (HTML/CSS/JS, מימין לשמאל, מותאם לטלפון).
- כל דפדפן מקבל מזהה אקראי, וכך המורה יכולה לבטל שיבוץ שעשתה מאותו מכשיר. ממכשיר אחר אפשר לבטל עם הקוד האישי, או לבקש מהמנהלת.
