# בית אור – שיבוץ שיעורים למרחב הלמידה

אתר לבית הספר **בנות מנחם**, שבו המורות משתבצות לשיעורים במרחב הלמידה "בית אור" וכותבות משובים על השיעורים.

**האתר החי:** https://beit-or-production.up.railway.app

## למורות

- **כניסה עם מספר טלפון:** כל מורה מקלידה את מספר הטלפון שלה, כפי שהוזן ברשימת המורות. הכניסה נשמרת במכשיר.
- **לוח שיבוצים לפי פרשת השבוע:** כל שבוע נקרא על שם הפרשה שלו ("פרשת בראשית", "פרשת נח"…), עם תאריך עברי ולועזי.
- ימים ראשון–חמישי **6 שיעורים**, ויום שישי **3 שיעורים** (ההנהלה יכולה לשנות). ההרשמה פתוחה **10 ימים קדימה** (ההנהלה יכולה לשנות), ובכל יום נפתח יום נוסף.
- שעה שמורה השתבצה אליה מוצגת כתפוסה, עם שם המורה והכיתה. אם שתי מורות לוחצות באותו רגע, רק הראשונה נקלטת.
- כל מורה רואה את השיבוצים הקרובים שלה ויכולה לבטל אותם.
- **מכסה שבועית:** אם ההנהלה הגדירה מגבלה, המורה רואה כמה שעות ניצלה בכל שבוע, ואחרי שהגיעה למכסה לא תוכל להשתבץ באותו שבוע.
- **כניסה כאורח:** צפייה בלוח השיבוצים בלבד, בלי אפשרות להשתבץ או לערוך, ובלי גישה לדף המשובים.
- **רשימת המתנה:** על שיעור תפוס אפשר להצטרף לרשימת המתנה. אם הוא מתבטל, הוא עובר אוטומטית לממתינה הראשונה (אם היא לא הגיעה למכסה), והיא מקבלת הודעה באתר.
- **הדפסת השבוע:** כפתור "הדפסת השבוע" מדפיס את לוח השבוע המוצג, בגודל A4 לרוחב.
- **דף המשובים:** אחרי שהשיעור התקיים, המורה כותבת משוב (ודירוג בכוכבים, לא חובה). כל המורות רואות את כל המשובים, ואפשר לסנן לפי מורה ולחפש.

## להנהלה ("כניסת הנהלה" במסך הכניסה, עם קוד ניהול)

- **מורות וטלפונים:** הוספה, עריכה, מחיקה, סימון "לא פעילה". אפשר גם להדביק רשימה שלמה, שורה לכל מורה: `שם, טלפון`.
- **מגבלת שעות שבועית:** הגדרה כללית לכל המורות (בלשונית "תאריכים וימי חופש"), ואפשר לקבוע מגבלה אחרת למורה מסוימת בעריכת המורה. ההנהלה יכולה לשבץ גם מעבר למגבלה.
- **תאריכים וימי חופש:**
  - תקופת הפעילות: מאיזה תאריך עד איזה תאריך אפשר להשתבץ.
  - שעות השיעורים: מוצגות ליד כל שיעור בלוח.
  - מספר השיעורים בכל יום (ברירת מחדל: 6 בימים א׳–ה׳, 3 ביום שישי). השינוי חל רק על שיבוצים חדשים, ושיבוצים קיימים נשארים.
  - כמה ימים מראש אפשר להשתבץ (ברירת מחדל 10, עד 90).
  - חסימת שיעורים ביום מסוים: בוחרים תאריך ושיעורים (למשל 3–4) וסיבה. המשבצות מופיעות כ"לא זמין". ההנהלה יכולה לשבץ בהן בכל זאת.
  - ימי חופש: יום בודד או טווח, עם שם. יש גם הצעות מהלוח העברי (חגים בחודשים הקרובים) שאפשר להוסיף בלחיצה.
- **שיבוצים קבועים:** אותו שיעור, באותו יום בשבוע, לאותה מורה, לאורך תקופה. השיבוצים נוצרים מראש, וימי חופש, שיעורים חסומים ושעות תפוסות מדולגים ומדווחים. ביטול שיבוץ קבוע מוחק רק את השיעורים העתידיים.
- **כל השיבוצים:** סינון לפי מורה, ביטול כל שיבוץ, וסימון אילו שיעורים קיבלו משוב. המנהלת יכולה גם לשבץ מורה ישירות מהלוח.

## טכני

- `server.js`: שרת Node ללא תלויות. הנתונים נשמרים בקובץ JSON בתיקייה `DATA_DIR`.
- `public/index.html`: האתר עצמו (מימין לשמאל, מותאם לטלפון).
- פרשות השבוע והחגים מגיעים מ־[Hebcal](https://www.hebcal.com) (לוח ארץ ישראל) ונשמרים במטמון ל־6 שעות.
- אפשר לשנות את מספר השיעורים, הימים וכמה ימים קדימה פתוח להרשמה ב־`CONFIG` בראש `server.js`.

### Railway

| משתנה | מה זה |
|---|---|
| `ADMIN_CODE` | קוד הכניסה להנהלה |
| `DATA_DIR` | `/data`, שם מחובר volume קבוע |

כל דחיפה לענף המחובר מעדכנת את האתר אוטומטית.

### הרצה מקומית

```
ADMIN_CODE=1234 npm start
```

ואז נכנסים ל־http://localhost:3000. נכנסים כהנהלה עם `1234`, מוסיפים מורה עם מספר טלפון, ואז אפשר להיכנס כמורה.
