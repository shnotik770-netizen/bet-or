# שפרה ופועה · מוסדות חב״ד עפולה

אפליקציית ווב לניהול ורישום יולדות וסידור מתנדבות. Next.js 16 + React 19 + Tailwind CSS 4 + Prisma 6 על PostgreSQL (Railway). ממשק בעברית, RTL מלא.

## מסכים

- **ראשי** – הוספה מהירה של יולדת (שם + טלפון), כמה כתובות יש היום בסדר היום, ומי נרשמה לאחרונה.
- **יולדות** (`/yoldot`) – הוספה מהירה, חיפוש, סינון לפי מוסד, עריכה ומחיקה.
- **טופס יולדת** (`/yoldot/new`, ועריכה) – **חובה רק שם וטלפון**. השאר לא חובה: כתובת, **העדפות** (אוכל, רגישויות, שעות), מוסדות (אפשר כמה), מי דיווח/ה (נבחר/ת אוטומטית לפי המדווח/ת הקבוע/ה של המוסד, ואפשר לשנות או להשאיר ריק), תאריך לידה, מין הנולד/ת, הערות.
  בעריכה יש גם **שיבוץ בסדר היום**: בוחרים תאריך ומה מביאים, ומבטלים ב-×.
- **סדר יום מתנדבות** (`/volunteers`) – לכל יום בשבוע (ראשון–שישי) הכתובות שהמנהל שיבץ, ממוינות לפי רחוב: שם, טלפון, מה מביאים, העדפות, הערות, ״הגעה 2 מתוך 5״, וכפתור ניווט בוויז.
  המנהל מוסיף יולדת ליום ישר מהמסך ומסיר בלחיצה. **כל מי שנכנס (גם מתנדבות) יכול לעדכן כתובת.** מעבר בין שבועות, תאריך עברי, הדפסה.
- **מוסדות ומדווחים** (`/institutions`) – מוסדות והמדווח/ת הקבוע/ה של כל מוסד.

## הרשאות

| משתנה | מי | מה רואים |
|---|---|---|
| `APP_PASSWORD` | הנהלה | הכול |
| `VOLUNTEER_PASSWORD` | מתנדבות | רק סדר היום, ועדכון כתובות |

בלי `APP_PASSWORD` האתר פתוח לגמרי (לפיתוח בלבד). הכניסה נשמרת במכשיר לחצי שנה.

## מסד הנתונים

`prisma/schema.prisma`: `Yoledet` (יולדת) ↔ `Institution` (מוסד, רבים-לרבים), `Reporter` (מדווח/ת, שייך/ת למוסד), ו-`Visit` (שיבוץ: יולדת + תאריך + מה מביאים).
תאריכים נשמרים כ-`DATE`. ״היום״ מחושב לפי שעון ישראל.

## הרצה מקומית

```bash
cp .env.example .env        # ולעדכן DATABASE_URL
npm install
npx prisma migrate dev      # יוצר את הטבלאות
npm run db:seed             # לא חובה: מוסדות לדוגמה
npm run dev
```

## העלאה ל-Railway

1. בפרויקט ב-Railway: **New → Database → PostgreSQL**.
2. **New → GitHub Repo** עם הריפו הזה, ובהגדרות השירות **Root Directory = `shifra-puah`**.
3. במשתנים של השירות: `DATABASE_URL = ${{Postgres.DATABASE_URL}}`, `APP_PASSWORD` ו-`VOLUNTEER_PASSWORD` (באתר יש שמות, טלפונים וכתובות).
4. `npm start` מריץ `prisma migrate deploy` לפני העלייה, כך שהטבלאות נוצרות לבד.
