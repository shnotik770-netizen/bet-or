# שפרה ופועה · מוסדות חב״ד עפולה

אפליקציית ווב לניהול ורישום יולדות וסידור מתנדבות. Next.js 16 + React 19 + Tailwind CSS 4 + Prisma 6 על PostgreSQL (Railway). ממשק בעברית, RTL מלא.

## מסכים

- **ראשי** – קיצורים ל״סדר יום מתנדבות״ ול״רישום יולדת״, מספרים, ההגעות של היום ומי נרשמה לאחרונה.
- **רישום יולדת** (`/yoldot/new`) – שם מלא, טלפון, כתובת מלאה (רחוב, מספר, דירה, עיר, הכוונה), מוסד, מדווח/ת מאותו מוסד, תאריך לידה, מין הנולד/ת, הערות.
  בנוסף, **סידור מתנדבות**: מתאריך עד תאריך (ברירת מחדל: 14 יום מיום הלידה), באילו ימים מגיעות (ברירת מחדל: א׳–ה׳), וסוג הסיוע (ארוחה / סיוע בבית / שניהם).
- **יולדות** (`/yoldot`) – רשימה עם חיפוש וסינון לפי מוסד, עריכה ומחיקה.
- **סדר יום מתנדבות** (`/volunteers`) – לכל יום בשבוע (ראשון–שישי) כל הכתובות שצריך להגיע אליהן, ממוינות לפי רחוב. לכל כתובת: שם, טלפון (לחיצה מחייגת), סוג הסיוע, ״יום 3 מתוך 10״, סימון ״הגעה אחרונה״, הערות, וכפתור ניווט בוויז. מעבר בין שבועות, תאריך עברי, והדפסת השבוע.
- **מוסדות ומדווחים** (`/institutions`) – הוספה, עריכה, השבתה ומחיקה של מוסדות ומדווחים. מוסד או מדווח/ת שיש להם דיווחים אפשר רק להשבית.

אין מנגנון סטטוס טיפול (לפי הבקשה).

## מסד הנתונים

הסכמה ב-`prisma/schema.prisma`: `Institution` (מוסד) ← `Reporter` (מדווח/ת) ← `Yoledet` (יולדת). השרת בודק שהמדווח/ת שנבחר/ה שייך/ת למוסד שנבחר.
תאריכים נשמרים כ-`DATE` (בלי שעה). ״היום״ מחושב לפי שעון ישראל.

## הרצה מקומית

```bash
cp .env.example .env        # ולעדכן DATABASE_URL
npm install
npx prisma migrate dev      # יוצר את הטבלאות
npm run db:seed             # לא חובה: מוסדות לדוגמה
npm run dev
```

## העלאה ל-Railway

1. בפרויקט ב-Railway: **New → Database → PostgreSQL**.
2. **New → GitHub Repo** עם הריפו הזה, ובהגדרות השירות **Root Directory = `shifra-puah`**.
3. במשתנים של השירות: `DATABASE_URL = ${{Postgres.DATABASE_URL}}`, ו-`APP_PASSWORD` (מומלץ מאוד, כי באתר יש שמות, טלפונים וכתובות).
4. `npm start` מריץ `prisma migrate deploy` לפני העלייה, כך שהטבלאות נוצרות לבד.

## כניסה

אם מוגדר `APP_PASSWORD`, כל האתר דורש סיסמה (עוגייה ל-90 יום). בלי המשתנה, האתר פתוח.
